## 1. 从 Linear 规范到 EasyGit 的适配原则

| 上游规范 | EasyGit 适配 |
| --- | --- |
| 营销页体系（80px 大标题、96px 段距） | **应用 UI 体系**：采用其色彩、表面层梯、发丝线、圆角、间距令牌；字体层级按桌面工具密度重定标（§4） |
| 暗色单主题（Do：不做亮色营销页） | 产品需要明/暗双主题（PRD §7）：暗色为默认与基准，亮色主题从规范 inverse 令牌推导（§3.2） |
| 「不引入第二种彩色」 | 仅约束营销语境；规范「Known Gaps」明确产品内使用更丰富的标签色板。EasyGit 据此扩展 **git 语义色**与**分支色板**（§3.3–3.4）， lavender 仍只用于主操作、焦点与选中态 |
| SF Pro / Linear 专有字体 | 采用其建议的替代方案：**Inter**（拉丁）+ 系统中文字体；等宽 **JetBrains Mono**（§4） |

核心气质保留：**近黑画布、四级表面层梯承载层级（不用阴影）、1px 发丝线、克制小圆角（8/12px）、lavender 稀缺使用、信息密度高、安静专业。**

## 2. 设计令牌命名与实现方式

- 实现为 CSS 变量，前缀 `--eg-`（EasyGit），由 `src/theme/tokens.css` 定义，主题切换即切换 `:root[data-theme="dark"|"light"]` 变量组。
- Tailwind v4 以 `@theme` 映射变量（如 `bg-surface-1` → `var(--eg-surface-1)`），组件层只允许引用语义令牌，禁止写死色值。
- 令牌分三层：**基础令牌**（本文件 §3–§4）→ **语义令牌**（§3.3 git 状态、§6 组件状态色）→ **组件令牌**（各组件规格直接引用语义令牌）。

### 3.3 Git 语义色（产品扩展，暗色值 / 亮色值）

用于三区状态视图、diff、变更列表徽标。命名 `--eg-git-*`。

| 语义 | 暗色 | 亮色 | 用于 |
| --- | --- | --- | --- |
| 新增 added | `#27a644` | `#1e7d38` | 新文件图标、diff 增行 |
| 修改 modified | `#e2b341` | `#9a7a1a` | 修改文件、diff 改行 |
| 删除 deleted | `#e5484d` | `#c73338` | 删除文件、diff 删行 |
| 重命名 renamed | `#4f8fd9` | `#2f6cb3` | 重命名/复制文件 |
| 冲突 conflict | `#f2994a` | `#c26a1d` | 冲突文件、冲突块标记（与删除的红区分） |
| 未跟踪 untracked | `#8a8f98` | `#6f737b` | 未跟踪文件 |
| 危险 danger | `#e5484d` | `#c73338` | 危险按钮（丢弃修改、强制推送） |

规则：语义色用于**小面积标识**（图标、文字、3px 左侧条、徽标点），禁止整块填充背景；diff 增/删行背景用对应色 10–12% 透明度。

### 3.4 分支 / DAG 色板（产品扩展）

历史 DAG 图与分支看板的分支着色，8 色循环分配，可在 `#010102` 底上相互区分且不与语义色混淆：

```
--eg-branch-1  #5e6ad2  lavender（默认第一支：当前分支优先分配）
--eg-branch-2  #4fa3e8  blue
--eg-branch-3  #38b8a4  teal
--eg-branch-4  #4c9e4d  green
--eg-branch-5  #e2b341  yellow
--eg-branch-6  #f2994a  orange
--eg-branch-7  #b06bd6  purple
--eg-branch-8  #e5647e  rose
```

规则：当前分支线宽 2.5px 且加 `--eg-ink` 描边光晕；其余 1.5px；`main`/默认分支优先分配 branch-1…按分支名哈希稳定分配，同一分支在 DAG 图与看板中颜色一致；亮色主题使用同一色板（均通过白底 3:1 图形对比度）。

## 4. 字体与中文排版

### 4.1 字体栈

```css
/* UI */
--eg-font-ui: "Inter", -apple-system, "SF Pro Text", "PingFang SC",
  "HarmonyOS Sans SC", "Microsoft YaHei UI", "Microsoft YaHei",
  "Noto Sans SC", "Segoe UI", sans-serif;
/* 等宽：哈希、分支名、diff、路径、命令透视 */
--eg-font-mono: "JetBrains Mono", ui-monospace, "SF Mono", "Cascadia Mono",
  Consolas, "PingFang SC", "Microsoft YaHei", monospace;
```

Inter 随应用打包（可变字重 400/500/600）；中文字体走系统栈，不打包以控制体积。

### 4.2 应用字号标尺（替代上游营销标尺）

| 令牌 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `--eg-text-title` | 16/1.4 | 600 | 页面标题、对话框标题 |
| `--eg-text-section` | 14/1.45 | 600 | 区块标题、面板标题 |
| `--eg-text-body` | 14/1.6 | 400 | 列表正文、说明文字（**基准字号**） |
| `--eg-text-secondary` | 13/1.5 | 400 | 次要说明、表单标签 |
| `--eg-text-caption` | 12/1.4 | 400 | 徽标、时间、路径、元信息 |
| `--eg-text-micro` | 11/1.3 | 500 | 底栏状态、DAG 角标 |
| `--eg-text-mono` | 13/1.6 | 400 | 哈希、命令、diff |

### 4.3 中文排版规则（对上游规范的强制修正）

1. **负字距仅用于拉丁与数字**：`letter-spacing` 负值规则只应用到英文语境；含中文的标题一律 `letter-spacing: 0`（中文负字距导致笔画粘连）。
2. 中文正文行高 ≥ 1.6（上游 1.5 偏紧）；按钮/标签中文行高 1.5。
3. 字重映射：Inter 600=标题、500=按钮/强调、400=正文；中文粗体由系统合成，标题用 600 而非 700，避免中文发虚。
4. 中西文混排自动留隙交给字体栈（Inter 与 PingFang/YaHei 混排已可接受），不手工加空格。
5. 术语表（PRD §6.7）中的英文原词以 `--eg-text-mono` 13px 灰色小字跟随展示，如「储藏 · stash」。

## 5. 布局系统

### 5.1 应用框架

| 区域 | 尺寸 | 表面 | 备注 |
| --- | --- | --- | --- |
| 顶栏 | 高 44px | `canvas` + 底部 `hairline` | 左：仓库切换器；中：页签（变更/历史/分支…）；右：同步按钮组、搜索 |
| 仓库栏（侧栏） | 宽 232px（可折叠至 48px 图标栏） | `surface-1` + 右侧 `hairline` | 仓库列表、收藏分组 |
| 主视图 | 弹性 | `canvas` | 页签内容区 |
| 详情面板 | 宽 360px（280–480 可拖拽） | `surface-1` + 左侧 `hairline` | 提交详情/diff/向导 |
| 底栏 | 高 28px | `canvas` + 顶部 `hairline` | 模式切换、撤销/重做、命令透视、任务进度（网络任务显示百分比；本地写操作显示「⟳ 正在…」操作名） |

主内容最大宽度不设限（工具型应用铺满），列表类内容区可设 1280px 阅读上限（呼应上游 max-width）。

### 5.2 间距令牌（沿用上游）

`--eg-space-1..8` = 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px（营销语境保留 96px 为 `--eg-space-section`，应用内不用）。

- 面板内边距：16px（应用密度高于营销的 24px）；卡片 16px；弹窗 24px。
- 列表行高：标准 32px、紧凑 26px（设置中可切换「紧凑密度」）。
- 圆角：按钮/输入框 8px（`rounded.md`）、卡片/弹窗 12px（`lg`）、徽标 pill 9999px、DAG 节点圆形。**禁用** CTA 胶囊化（上游 Don't 保留）。

### 5.3 层级与阴影（沿用上游「层梯即深度」）

| 层级 | 处理 | 用于 |
| --- | --- | --- |
| L0 | `canvas`，无边框 | 主视图底 |
| L1 | `surface-1` + `hairline` | 侧栏、卡片、详情面板 |
| L2 | `surface-2` + `hairline-strong` | 悬停卡片、选中页签、内嵌代码块 |
| L3 | `surface-3` + `hairline` | 下拉菜单、右键菜单、命令面板 |
| 弹窗 | `surface-2` + `hairline-strong` + 遮罩 `--eg-overlay`，可加 `0 8px 32px rgba(0,0,0,.45)`（暗色下唯一的柔和投影，用于分离感） | 对话框、向导 |
| 焦点环 | 2px `--eg-primary-focus`，50% 不透明度，偏移 0 | 所有可交互元素 |

## 6. 组件规格（EasyGit 组件清单）

> 通用状态定义：Hover=表面升一级或加 6% 白（亮色加 4% 黑）；Active=再升一级；Focus=焦点环；Disabled=`ink-tertiary` 文字 + 无边框。以下只列差异项。

### 6.1 按钮

| 变体 | 背景 | 文字 | 用途 |
| --- | --- | --- | --- |
| Primary | `primary`（hover `primary-hover`） | `on-primary` | 每屏最多一个：提交、确认推送 |
| Secondary | `surface-1` + `hairline` | `ink` | 次要操作 |
| Tertiary（文本按钮） | 透明 | `ink-muted`，hover `ink` | 工具条、内联操作 |
| Danger | `danger` 10% 背景 + `danger` 文字 + `danger` 40% 边框；确认态实底 | `danger` | 丢弃修改、删除分支、强制推送 |
| Inverse | `#ffffff`/暗 或 `#18191b`/亮 | 反色 | 极少数强 CTA（首页引导） |

尺寸：高 28px（紧凑）/ 32px（标准，默认）；内边距 8px×14px；圆角 8px；字号 13px/500。

加载态：请求进行中显示 14px 旋转图标（`animate-spin`），保留原标签（宽度不跳）并自动禁用。网络操作与可能耗时数秒的写操作（提交、切换分支、合并、储藏等）都应使用该状态，避免出现「点了没反应」。

### 6.2 输入与表单

- 输入框：`surface-1` 背景、`hairline-strong` 边框、8px 圆角、高 32px、内边距 8×12；聚焦边框不变、外加焦点环；错误态边框 `danger` + 下方 12px 错误文案（补上游缺口：表单校验样式）。
- 复选框：16px、6px 圆角，选中 `primary` 实底白勾（三区视图勾选即暂存）；批量选择的表头复选框支持半选态（`primary` 实底减号，`aria-checked="mixed"`）。
- 下拉选择器（`Select`）：触发器高 28px（紧凑）/32px（标准），`surface-1/2` 背景 + `hairline-strong` 边框 + 8px 圆角，右侧 14px chevron；展开菜单 `surface-3` + `hairline` + 8px 圆角 + `--eg-shadow-dialog`，选项行高约 28px、字号 13px，选中项 `ink` 文字 + 右侧 `primary` 勾。键盘：Enter/Space/方向键打开，方向键移动，Enter/Space 选择，Esc 关闭；点击外部关闭。
- 开关：36×20，选中 `primary`。

### 6.3 页签（顶栏主导航）

上游 pricing-tab 迁移：默认 `canvas` 底 `ink-subtle` 文字；选中 `surface-2` 底 `ink` 文字；pill 圆角、高 28px、内边距 6×14。带徽标（变更数、领先/落后数）。

### 6.4 列表行（变更列表 / 分支列表 / 仓库列表）

- 结构：左状态图标（语义色）→ 主文字（文件路径 / 分支名）→ 右侧元信息（+/- 行数、领先落后徽标、时间）。
- 悬停 `surface-1`；选中 `surface-2` + 左侧 3px `primary` 竖条；行高 32px。
- 文件路径用 `mono` 13px；目录部分 `ink-subtle`，文件名 `ink`。

### 6.5 徽标（Badge）

Pill 形、`surface-2` 底、`caption` 12px、内边距 2×8。计数徽标：`primary` 实底白字（未读/待提交数）；语义徽标：语义色文字+10% 底。

### 6.6 Diff 视图

- 行高 22px，`mono` 13px；行号列宽 44px 右对齐 `ink-tertiary`，固定左置。
- 增行：语义 added 10% 底 + 文字正常；删行：deleted 10% 底 + 原文不删除线；改行内词级高亮：added/deleted 22% 底。
- Hunk 头：`surface-1` 底、`caption` 字号、右侧悬浮操作条（暂存此块/撤销此块，tertiary 按钮）。
- 展开上下文：hunk 头上「⋯ 展开 N 行」按钮。
- 超大文件：>5000 行折叠 + 「在独立窗口打开」。

### 6.7 历史 DAG 图

- 画布：`canvas` 底；节点 8px 圆（合并提交 8px 菱形），分支线 1.5px、当前分支 2.5px（§3.4 色板）。
- 行高 30px；左列 DAG 宽 96px；提交摘要 `body` 14px，超出省略；右侧元信息列：作者（头像 16px 圆）、相对时间（`caption`）、哈希（`mono` `ink-tertiary`）。
- 选中行：`surface-1` 底 + 左 3px `primary`；HEAD 节点：`ink` 描边环。
- 悬停行尾浮现快捷操作组（tertiary 图标按钮：详情/检出/摘取/回滚/在此建分支）。
- 角标：未推送 ↑n / 未拉取 ↓n（`primary` / `success` 底 pill `micro` 字号）。

### 6.8 冲突解决向导

- 全屏接管主视图：顶部进度条（`primary` 填充）+「解决冲突 3/7」；右下常驻「中止合并」（Danger Tertiary）。
- 三栏对照：基础/我方/对方，列头用 `caption`+语义色点；冲突块以 `conflict` 12% 底 + 左 3px 条标出。
- 每冲突块操作组：用我的 / 用对方的 / 两者保留 / 手动编辑（Secondary 按钮 24px 高）。
- 已解决块：整块降饱和 + 打勾标记；全部完成时底部出现 Primary「完成合并」。

### 6.9 命令面板（Ctrl/Cmd+K）

- 居中 640px 宽、`surface-3` 底、12px 圆角、`hairline-strong` 边框、顶部搜索框无边框 44px。
- 列表分组（建议操作/仓库/分支/文件/命令），选中项 `surface-2`；底部 `caption` 键位提示条。

### 6.10 操作时间线（reflog 可视化）

- 垂直时间线：左列时间（`caption`），中线 1px `hairline`，节点 8px 圆按操作类型着色（提交=branch 色、重置/强推=danger、合并=branch-2）；危险操作节点带 `danger` 描边。
- 悬停节点显示「恢复到此状态」按钮（Danger Secondary + 确认）。

### 6.11 其余标准组件

对话框（`surface-2`+`hairline-strong`+12px 圆角+24px 内边距）、Toast（右下角 `surface-3`，成功/错误用语义色图标，4s 自动消失，错误可展开详情；失败原因经「详情」展开为等宽滚动块 `surface-2`，错误 toast 停留 8s——TDD §11 2026-09-12 记录）、右键菜单（`surface-3`、8px 圆角、项高 28px、分组分隔线）、Tooltip（`surface-3`、`caption`、延迟 300ms、术语悬浮卡含英文原词+解释）、空状态（居中插画区+`ink-subtle` 说明+引导按钮）、进度条（4px 高、`primary` 填充，用于克隆/推送/向导）、骨架屏（`surface-1` 底 + 6% 白闪烁）、**全局等待条**（用户发起的写/网络操作进行中时，窗口顶部 2px `primary` 不确定进度条 + `animate-pulse`，绝对定位 `z-50` 不挤动布局；开始 150ms 内不显示、显示后至少停留 300ms，避免瞬时操作闪烁；只读查询与 fs-watch 后台刷新一律不触发）。

**日志面板**（设置页「日志」区，TDD §1 文件 sink 的界面入口；只读，不做终端——PRD §1.5）：复用设置页 SectionCard；首行 `surface-2` 文件下拉（每日滚动文件倒序，名称+大小）+ 右侧级别过滤 chips（全部/错误/警告/信息，选中态 `primary` 实底）；内容区 `surface-2`+`hairline` 圆角块，等宽 `caption`，`max-h-96` 内滚动，`whitespace-pre-wrap`；截断时左下注「仅显示末尾部分」；底部右侧三个次级按钮：刷新 / 复制 / 打开文件夹（opener 插件）；目录路径以等宽 `ink-tertiary` 小字收尾。空内容显示 `logs.filter.empty` 空态文案。

## 8. 动效

| 场景 | 规格 |
| --- | --- |
| 通用过渡 | 120ms ease-out；悬停反馈 80ms |
| 弹窗/向导进入 | 160ms 淡入 + 4px 上移 |
| 页签切换 | 内容 100ms 淡入，无位移动画 |
| DAG 图 | 平移/缩放 0ms 跟手；节点悬停即时响应；**不做**进入动画 |
| 长任务 | 进度条平滑插值；完成时 Toast 淡入 |
| 系统设置「减少动效」 | 全部动画降为直接切换（`prefers-reduced-motion`） |

## 9. 图标

- 图标库：**Lucide**（线性、1.5px 描边，与发丝线气质一致），`lucide-react`。
- 尺寸：16px（列表/按钮内）、14px（徽标/底栏）、20px（空状态/引导）；描边色随文字色。
- Git 语义图标固定映射：新增=plus-circle、修改=pen-line、删除=trash-2、重命名=arrow-right-left、冲突=alert-triangle、未跟踪=file-question、分支=git-branch、储藏=archive、标签=tag、远程=cloud。

## 10. 无障碍与密度

1. 文本对比度 ≥ 4.5:1（`ink-subtle` 在 `canvas` 上 ≈ 6.3:1，达标；`ink-tertiary` 仅用于 ≥12px 辅助信息）。
2. 焦点环不可移除；全键盘可达：Tab 顺序 = 视觉顺序，列表支持 ↑↓ 移动 + Enter 确认。
3. 色盲兜底：git 状态除颜色外必有图标 + 文字；DAG 分支以线型（实线/虚线=远程）辅助区分。
4. 触控/点击目标 ≥ 28px（桌面鼠标为主），列表行整行可点。
5. 密度：标准（行高 32px）/紧凑（26px）全局切换，专家模式默认提供。

## 11. Do / Don't（EasyGit 语境）

**Do**
- lavender 只用于：主按钮、选中态、焦点环、当前分支标识、链接强调。
- 用表面层梯 + 发丝线表达层级；同一屏表面层级不超过 3 级。
- 危险操作永远「红色文字 + 需要确认」，且底栏可撤销。
- 中文文案遵循术语表；技术原词以等宽小字辅助。
- 长列表一律虚拟滚动。

**Don't**
- 不引入语义色板之外的装饰性彩色；不做渐变、不做光斑卡片。
- 不用纯黑 `#000000` 做底色；不用大面积阴影分层（弹窗除外）。
- 不把危险按钮做成实底大按钮放在主流程显眼位（降低误触）。
- 不在中英混排标题上使用负字距。
- 不用原生 `alert/confirm`（一律应用内对话框，保证主题一致）。
