# 新手 10 分钟测试（m1-plan X-04，PRD §8 验收 #2）

> 目标：**完全不会命令行的用户**在 10 分钟内完成「克隆 → 修改 → 提交 → 建分支 → 合并」，
> 全程零命令行。通过标准（PRD §8.2）：5 名无 Git 经验用户 ≥ 90% 独立完成。
> 测试主持：给被试只读本文档的「任务卡」部分，不演示、不提示。

## 任务卡（给被试）

你正在使用 EasyGit——一个不需要命令行的 Git 图形工具。请依次完成 5 个任务；
每完成一步，界面上的文字或数字会发生变化。

1. **克隆一个示例项目**：点击「新建仓库」旁的「克隆仓库」，地址填
   `{由主持提供，指向本机示例仓库}`，选择保存位置，等待完成。
2. **做一点修改并提交**：打开克隆好的仓库；在文件里随便改一行（用系统记事本）。
   回到 EasyGit「变更」页，勾选改动过的文件，在下方输入一句说明，点「提交」。
3. **建一个分支**：切到「分支」页，点「新建分支」，起名叫 `my-idea` 并切换过去。
4. **再改一次并提交**：在 `my-idea` 分支上再修改一个文件并提交（同任务 2 的做法）。
5. **合并回主线**：切回 `main` 分支，在「分支」页找到 `my-idea`，右键「合并…」，
   保持默认（快进优先）并确认。回到「历史」页应该能看到合并后的记录。

完成后告诉主持：过程中哪一步最难懂？（口述即可）
