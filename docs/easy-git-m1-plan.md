| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |

## 1. 里程碑总览

| 周 | 主题 | 可演示成果（每周五验收） |
| --- | --- | --- |
| W1 | 脚手架与设计系统 | 空应用三平台出包，明暗主题与应用框架布局可切换 |
| W2 | 仓库打开与状态底座 | 打开本地仓库，看到三区状态概览，改文件自动刷新 |
| W3 | 变更与暂存闭环 | 勾选暂存/取消/丢弃文件、忽略规则生成（尚不能提交） |
| W4 | 提交与命令透视 | 完成首次提交（含 amend），命令透视与错误人话化可用 |
| W5 | 历史 DAG 图 | DAG 图渲染 + 提交详情 + 过滤搜索，虚拟滚动流畅 |
| W6 | Diff 与逐块暂存 | diff 视图 + hunk/行级暂存，部分文件提交 |
| W7 | 分支/标签/储藏 | 建删改分支、切换、标签、储藏全流程 |
| W8 | 合并/回退/冲突向导 | merge + 冲突向导走通 + revert/reset 三模式 |
| W9 | 远程与安全网 | fetch/pull/push、凭据钥匙串、快照点/撤销/操作时间线 v1 |
| W10 | 打磨与 RC | 性能达标、引导与空状态、bugbash、发布 0.1.0-rc |

依赖主线：W1 基建 → W2 状态底座 →（W3→W4 变更流）∥（W5→W6 历史流）→ W7 → W8 → W9 → W10。两人分工时 W3-4 与 W5-6 并行，整体可提前约 2 周。

## 4. 裁剪顺序（进度落后时，从上往下砍）

1. F-11 概念卡片、F-26 安全默认提示 → 挪 M2
2. F-14 设置页精简为最小项 → 挪 M2
3. R-14/F-20 blame 与文件历史（本就是 P2）→ 挪 M3
4. F-23 命令面板完整版 → 降级为仅操作搜索
5. **不可裁剪底线**：三区暂存、提交、DAG、分支、merge/冲突向导、fetch/push、撤销/回收站——砍任何一项即 M1 定义不成立，应顺延工期而非砍范围。
